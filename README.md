# AI Coding Agent

A Python-based AI coding agent built as part of the [Boot.dev](https://www.boot.dev/) backend development curriculum.

## About

This project was created to learn how AI agents interact with files, execute Python scripts, and use function calling to perform programming tasks.

## Features

- List files and directories
- Read file contents
- Execute Python scripts with optional arguments
- Create and overwrite files
- Handle errors and validate file paths
- Use an LLM to select and execute functions

## Technologies

- Python
- Google Gemini API
- uv
- Git

## What I Learned

- Working with LLM APIs
- Defining function schemas
- Implementing function calling
- File handling and directory management
- Running Python scripts using subprocess
- Error handling and basic security restrictions
